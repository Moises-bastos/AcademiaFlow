# AcademiaFlow

Estrutura inicial do projeto AcademiaFlow, desenvolvido com TypeScript.

## Instalação

```bash
npm install
```

## Executar em desenvolvimento

```bash
npm run dev
```

## Gerar build

```bash
npm run build
```

# As pastas estão organizadas por responsabilidade: domínio, apresentação, armazenamento e documentação.

um projeto de POO com Um projeto em TypeScript, envolvendo herança, polimorfismo, encapsulamento, classes abstratas e organização em camadas.
